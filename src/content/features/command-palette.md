Every action in Torrenta is a command: one definition used by the menu, the list's context menu, the toolbar and the palette. That is why the four can never disagree, and why the palette can offer all of them.

- **Open it with `Alt+X`**, Editora's `M-x`. Settings → General → Keyboard can make it `Ctrl+Shift+P` instead, applied at once; the View menu and the toolbar say which is in force.
- **Type part of a name.** "seq" finds Sequential Download, "loc" finds Set Location…; each row shows its chord, so the next time you can skip the palette.
- **It acts on the selection**, like the menus: select ten torrents, `Alt+X`, "recheck", `Enter`.
- **The omnibox hands over to it.** Type `>` in the filter box and the palette opens with what you typed.
- **Commands the engine cannot do are not there.** With a Transmission daemon as the engine, the creator and a few other commands are hidden from the palette as well as the menus, so a chord never does nothing.

The [keybindings page](/keybindings) lists every command, generated from the app's own command list.
